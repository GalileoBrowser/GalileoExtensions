Current installation flow

Verify. Review. Enable.

  1. 01
    Open Get Extensions

    Use Galileo's application menu to open the official catalog.

  2. 02
    Verify exact files

    Galileo downloads only the advertised flat JSON and CSS files and checks every SHA-256 digest.

  3. 03
    Review the package

    Inspect its identity, hosts, permissions, static rules, and content-style scope before installing it disabled.

  4. 04
    Enable explicitly

    Complete a second permission review. Private-window access remains a separate choice.

Choose Review in Galileo to return to the browser-owned verifier. Automatic installation and unattended updates stay disabled until Galileo has signed packages, revocation, and a browser-owned update pipeline. Other browsers and older Galileo builds can still use the downloadable flat bundle.
